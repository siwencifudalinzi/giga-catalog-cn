# GIGA 官方中文标签索引设计

## 目标

把 GIGA 官网每部影片详情页的“ジャンルタグ”和“キャラクタータグ”完整同步到公开目录，以中文为主显示，支持标签索引、搜索、多标签包含/任意/排除筛选，同时不破坏现有每日目录同步和失败关闭。

## 已验证的官网结构

- 入口：`https://www.giga-web.jp/search/tag.php`。
- 全部类型标签：`tag.php?mode=1`，当前解析到 533 个。
- 全部角色标签：`tag.php?mode=2`，当前解析到 196 个。
- 详情页标签链接形式：`../search/index.php?tag_id=<integer>`。
- 详情页会将标签分入“ジャンルタグ”与“キャラクタータグ”容器。
- 产品页直连会跳回 `top.php`；需要年龄门 Cookie 和同站 Referer。

## 数据模型

`public/data/catalog.json` 保持 `schemaVersion: 1` 的向后兼容增量字段：

```json
{
  "tags": [
    {
      "id": 6,
      "group": "genre",
      "nameJa": "陰落",
      "nameZh": "沦陷",
      "count": 128
    }
  ],
  "series": [
    {
      "videos": [
        {
          "code": "SPSF-1",
          "tagIds": [6, 25, 2342],
          "tagsUpdatedAt": "2026-08-20T00:00:00Z"
        }
      ]
    }
  ]
}
```

标签 ID 是关联键，中文名称不参与关联，改译名不会破坏影片索引。`data/raw/tags.json` 保存官网原名、中文映射和来源状态；影片只保存 ID，避免在 3788 条记录中重复名称。

## 中文映射

1. 已审核词典优先，统一“女英雄”、“战队”、“黑丝袜”等用词。
2. 新标签用日语到简体中文的机器翻译生成候选，结果持久化，日常浏览不调用翻译服务。
3. 保留 `nameJa` 供日文搜索和后续校订；页面主文案只显示 `nameZh`。
4. 自动审查空译文、明显错译和未翻译假名，高频标签优先人工校正。

## 同步流程

1. 首次回填抓取 729 个官方标签及全部影片详情页，按 `productId` 断点续传。
2. 每日同步先执行原有目录发现，再只为新片或过期记录抓详情。
3. 详情页失败时保留上次 `tagIds`；新片标签失败不伪造空列表，记录未完成状态供下次重试。
4. 发布前验证标签 ID 唯一、所有影片引用可解析、计数一致、标签不含私有数据。

## 前端

- 新增“标签索引”视图，分为“类型与玩法”和“角色与造型”，显示中文名和影片数。
- 点击标签进入筛选；可选“全部包含”、“包含任意”和“排除”。
- 常规搜索同时匹配番号、标题、演员、日文标签和中文标签。
- 卡片最多显示 3 个标签和 `+N`；详情页按组展示全部标签。
- 320/390px 用单列标签抽屉，768px 与桌面使用可换行索引；不把标签放入 URL 或 `data-*` 以外的私有字段。

## 验收

- 公开目录所有影片都有已成功抓取的标签状态，官网确实无标签的影片可为空。
- 官网标签目录、影片引用和前端计数一致。
- 现有 Python/JavaScript 测试全部通过，新增抓取、合并、搜索、筛选和失败保留测试通过。
- 320/390/768/1440px、200% 缩放、键盘和 reduced-motion 通过真实浏览器验收。
- GitHub Pages 生产站加载新数据，标签索引和组合筛选可用。
